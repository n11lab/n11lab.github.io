# Enterprise Digital Accessibility Design System & WAI-ARIA Compliance Engine ## Executive Overview Architected and deployed by **Nitesh Kumar**, this repository serves as a fully standards-compliant, 100% screen-reader accessible digital design system. It directly bridges foundational IT governance and assistive technology workflows with international accessibility mandates (W3C WCAG 2.1/2.2, Section 508, GIGW). ## Consolidated Credential Foundation This project synthesizes core competencies from four recognized certifications: 1. **Career Edge IT (94% Distinction)** – NIIT Foundation: Enterprise document engineering and systemic structures. 2. **Diploma in Assistive Devices in Computer Application (DADCA)** – NAB Delhi: Native NVDA/TalkBack screen reader telemetry and non-visual interaction. 3. **IAAP CPACC Certification Preparation 3.0 (5.0 IAAP ECs)** – Deque University: Disability frameworks, universal design principles, and international accessibility mandates. 4. **Accessibility Fundamentals (1.5 IAAP ECs)** – Deque University: Core POUR standards and success criteria categorization. ## Key Technical Features - **Semantic Landmark Architecture:** Native HTML5 landmark elements complemented with WAI-ARIA 1.2 roles (`banner`, `navigation`, `main`, `contentinfo`). - **Interactive Accessible Components:** - Accessible Accordion with dynamic `aria-expanded` and `hidden` attribute binding. - Fully accessible Modal Dialog with keyboard trap prevention, `Escape` key dismissal, and programmatic focus restoration. - Screen reader Live Region (`aria-live="polite"`) for real-time status reporting without page reloads. - **Accessible Form Validation:** Programmatic association using `aria-required`, `aria-invalid`, and `aria-describedby` error messaging. - **Focus Management:** Visible high-contrast focus outlines satisfying WCAG 2.4.7 and dedicated bypass links (WCAG 2.4.1).
